Uploads save to a draft. Publishing makes a complete set eligible for daily and practice puzzles. Existing rounds keep their original screenshots. Replacing a draft or unpublishing keeps those older images available.

Capture checklist

Use Atlas's portal visibility controls to choose which portals appear. Hide labels and route lines if they would reveal too much, then use Screenshot. Upload one image for each of the six clues.

PNG, JPEG and WebP still images are supported (8 MiB upload/output, 24 megapixels maximum). Portle preserves the pixels and orientation, normalizes them to PNG and removes embedded metadata. It does not generate clues or infer a map from a screenshot.

This editor is for the owner of this local installation. It is available only on this computer; do not expose the authoring server publicly.
